# c_sockets
Testing c sockets
=======
Testing out c sockets just for fun :)
To use the client and server , use gcc to compile the two.
    gcc -o file file.c
Run the server
    ./server
 Finally run the client
    ./client <ipaddr>

In this case the sockets works on loopback address only, so use 127.0.0.1 and the argumet in client
    ./client 127.0.0.1
